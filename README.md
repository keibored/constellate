# Constellate

A real-time collaborative focus space where friends can study together in shared virtual rooms.

Intended architecture:

React + TypeScript
↓
Node.js + Express
↓
Socket.IO
↓
PostgreSQL
↓
Redis

This repository currently establishes the requested project structure and package configuration. Planned future additions are intentionally not implemented yet:

- Socket.IO
- PostgreSQL
- Prisma
- Redis

The current implementation is limited to a TypeScript React + Vite client and a TypeScript Express server foundation.
